# 键盘小勇士

给孩子用的键盘练习页。认字母、青蛙过河、拼单词，三关都在浏览器里完成，不需要安装。

## 打开方式

直接双击 `index.html`，用 Chrome、Edge 或 Safari 打开即可。

如果浏览器限制本地页面的存储或发音，可以在项目目录里启动一个本地服务：

```bash
python3 -m http.server 8765
```

然后访问 [http://127.0.0.1:8765](http://127.0.0.1:8765)。

## 怎么玩

建议按这个顺序：

1. **认识键盘**：屏幕亮起目标键，在电脑键盘上按下对应的键。可以切换字母、手指家园（ASDF JKL）、数字或全部按键。连对会加分，每 5 次连击得一颗星。
2. **青蛙过河**：用 `←` `→` 对准荷叶或木头，按上面的字母往前跳。最后一排按 `↑` 上岸。掉进水里扣一条命，连续过河 5 次算一轮。难度有轻松、普通、挑战。
3. **拼写单词**：看中文、听发音，把英文字母一个一个敲出来。屏幕上的黄色键就是下一个字母。

屏幕上的按键和大字母也可以用鼠标点。右上角的「音效」可以开关提示音，单词朗读不受这个开关影响。星星、词库勾选和音效开关都保存在这台电脑的浏览器里。

## 词库

内置词库：动物、颜色、食物、学校、家庭、自然、动作。首页默认勾选前三个。

家长可以在「管理词库 / 导入单词」里导入课文单词，支持：

- 每行一个单词：`apple`
- 单词加中文：`apple,苹果`（逗号可以是英文或中文）
- JSON 数组，或 `{ "words": [...] }`
- 上传 `.txt`、`.csv`、`.json`

`sample-words.txt` 是一份可以直接导入的例子。重复单词会自动跳过。自定义词库只存在本机浏览器中，清空后无法恢复。
